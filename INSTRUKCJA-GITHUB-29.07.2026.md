# Instrukcja przeniesienia na GitHub

## Najprościej

1. Otwórz repozytorium Pyk Łyk na GitHubie.
2. Zaznacz wszystkie pliki znajdujące się w folderze `PUBLIKACJA 29.07.2026 - PONIZEJ 100 PLIKOW`.
3. Przenieś je do głównego katalogu repozytorium.
4. Jeśli GitHub zapyta o zastąpienie plików, wybierz zastąpienie.
5. Zapisz zmiany przez **Commit changes**.

Nie przenoś samego folderu jako dodatkowego poziomu. Na GitHubie plik `index.html` ma znajdować się bezpośrednio w głównym katalogu repozytorium.

## Po publikacji

Otwórz:

`https://pyklyk.pl/`

Następnie sprawdź kalkulator:

`https://pyklyk.pl/kalkulator.html`

## Czego nie zmieniać

Nie zmieniaj nazw ani położenia:

- `assets/`,
- `shared/`,
- `kalkulator.html`,
- `polityka-prywatnosci.html`,
- `.nojekyll`.

## Arkusz leadów i e-mail

Strona korzysta z istniejącego wdrożenia Google Apps Script. W Google Apps Script musi być aktywna **Wersja 5 z 29 lipca 2026**. Zawiera ona także statusy `Umowa` i `Konkurencja`.

Jeśli wdrożenie zostanie kiedyś zmienione, wybierz nową wersję kodu i ponownie zaktualizuj wdrożenie. Nie zmieniaj adresu Web App wpisanego w kalkulatorze.
